Local Display Server - Third Party Notices
================================================

FFmpeg
------
The Windows installer workflow downloads the FFmpeg command-line executable used for media conversion and HLS streaming.

Windows build provider: https://www.gyan.dev/ffmpeg/builds/
FFmpeg project: https://ffmpeg.org/
FFmpeg source: https://github.com/FFmpeg/FFmpeg
License information: https://ffmpeg.org/legal.html

The release-essentials build used by the workflow is distributed separately under its own license terms. If you redistribute an installer containing FFmpeg, you are responsible for complying with the license terms of the exact build you distribute.
