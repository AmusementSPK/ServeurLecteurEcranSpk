LOCAL DISPLAY SERVER - VIDAA / TV WEB PLAYER
=============================================

The built-in TV web player is hosted by the server itself.

Default URL:
    http://<SERVER_IP>:8090/vidaa/

Typical setup:
1. Install and start Local Display Server.
2. Create at least one screen in the web administration panel.
3. On the TV, open its browser or web-app launcher.
4. Open http://<SERVER_IP>:8090/vidaa/
5. Select the screen this TV should represent.

The selected screen ID is stored in the TV browser's localStorage, so renaming
a screen on the server does not break the assignment.

Mouse/pointer:
- hover over a screen and left-click to select it;
- during playback, left-click to reopen the selector;
- moving the pointer to the top/bottom edge automatically scrolls long lists.

Remote-control support:
- Up / Down changes selection;
- OK confirms;
- Back returns to the selector.

The web player does not loop media itself. It consumes the continuously generated
HLS stream from the server.
